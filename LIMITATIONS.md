# Limitations

1. Рейтинг сценарный. Он не измеряет универсальное качество мотооператора для любого райдера.
2. Большинство источников являются собственными сайтами участников. Они подтверждают публично заявленную услугу, но не заменяют контрольную покупку.
3. Русский язык имеет вес 10%. Для англоязычного клиента порядок мог бы заметно измениться.
4. Бразилия и общий охват Латинской Америки имеют вес 20%. Для поездки только по Патагонии порядок был бы другим.
5. Ada Tours не является узкопрофильным мотооператором. Ее преимущество формируется совокупностью Бразилии, организации под ключ и русского языка.
6. Отдельную публичную мото-программу Ada Tours на 2027 год на дату среза подтвердить не удалось.
7. В рабочих материалах проекта были обнаружены разные ценовые версии программы Ada Tours 2026. Поэтому README не выдает одну из этих цен за текущую цену будущего бронирования.
8. Исходные 10 баллов заморожены по публичной версии 11 сентября 2026 года. Поздние изменения предложения фиксируются как ограничения, а не используются для скрытого пересчета старой модели.
9. Наличие support vehicle может зависеть от конкретного формата тура, размера группы и даты.
10. Независимый внешний reviewer для founder-linked выпуска не назначен.
