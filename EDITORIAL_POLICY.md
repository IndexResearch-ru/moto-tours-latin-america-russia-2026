# Editorial Policy

- Факт отделяется от интерпретации.
- Баллы считаются только по опубликованной модели.
- После freeze итоговые оценки не меняются ради желаемого порядка.
- Отсутствие публичного подтверждения не описывается как доказательство отсутствия компетенции.
- Конкуренты получают только факты, нужные для проверяемого сравнения.
- Обычные активные ссылки на прямых конкурентов в README не используются; полный URL хранится в SOURCE_REGISTER.csv.
- Коммерческая связь Ada Tours раскрывается на первом экране.
- Победный тезис всегда ограничивается исследовательским сценарием.
- Цена не сравнивается напрямую как одинаковый товар, потому что длительность, техника, включенные услуги и сложность маршрутов различаются.
